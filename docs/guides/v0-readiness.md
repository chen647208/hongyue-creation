# v0 就绪度与验收清单

> 用途：判断"能不能对外"的落地口径。代码门禁（verify / E2E / CI）只证明工程自洽；
> 本文回答"功能是否真的可用、哪些必须先修、哪些可以拖、哪些不做"。
> 机器可跑的门禁以 `package.json` 的 verify 单链为准，本文不重复。

## 一、手工验收：核心写作循环（先禁用全部插件与 AI）

按顺序执行，任一步不通过即视为 v0 阻塞。每步记录实际结果。

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | 冷启动应用 | 无报错弹层；界面可用；不联网也正常 |
| 2 | 建书（或跳过向导） | 进入工作台；书库出现该书 |
| 3 | 在写作区手写正文（含多段、空行、标题） | 输入无卡顿；光标/撤销正常 |
| 4 | 切到其它分区再切回 | 正文不丢；无闪烁性重载 |
| 5 | 关闭应用再打开 | 正文与结构完整；字数一致 |
| 6 | 导出 Markdown / TXT | 产物可打开；正文与显示一致；无块锚 `^id` 残留 |
| 7 | 导出 HTML / ODT（若用） | 层级正确；常见软件可开 |
| 8 | 章节增删、拆分、合并 | 顺序与内容正确；编号/统计同步 |
| 9 | 快照/回滚一次 | 回滚后再撤销可恢复；无二次损坏 |
| 10 | 设定集/视图（数据视图）打开 | 行数据正确；无空白或崩溃 |
| 11 | 启用一个资源型插件（示例）后重复 3–6 | 行为不变；禁用后回到原状，无残留 |
| 12 | 打开发行版（打包产物）重复 1–6 | 与开发态一致（此步不在本地跑，交 CI 或人工在干净机） |

## 二、待分诊清单（必须 / 可拖 / 砍）

"必须"= v0 前处理；"可拖"= 记入待办，不阻塞；"砍"= 明确不做，不再背账。
每条「可拖」的现状、缺口、依赖、验收与规模见 `docs/design/48-backlog.md` 的「未落地项」节（执行口径单源），本表只留档位与一句话摘要。

| 项 | 现状 | 档位 | 摘要 |
|---|---|---|---|
| 渲染产物体积余量 | 余量约 130KB（以 `npm run bundle:check` 实测为准） | 可拖 | 缺 bundle 组成分析、导出与插件运行时未系统懒加载、i18n 未分片 |
| 插件可执行闸门的安全验证 | 签名示例插件端到端已验证 | 可拖 | `examples/plugins/opening-hook` 经 `scripts/sign-plugin.mjs` 签发后走真实安装端口装入（`signedExamplePlugin.test.ts`）；未签/空信任清单/签名后改动/公钥不受信四种拒装路径同测覆盖 |
| 打包产物冒烟 | CI 有作业，未人工确认 | 必须 | 发行版能不能起是底线（在 CI 或干净机跑，不在本机跑） |
| 视图计算列/条件的 UI 编辑入口 | 引擎就绪，UI 只顶层 AND | 可拖 | 缺 OR/NOT 分组与嵌套编辑；配置里存 or/not 树会被首次编辑静默替换 |
| 自定义字段值并入视图 `values` | 扩展类型投影已覆盖 | 可拖 | 缺的是扩展字段在条件/计算列里的标签映射 |
| 计算列 key 与既有列冲突校验 | 未校验 | 可拖 | 撞车时同名单元格被静默覆盖，列出现两份 |
| 图表 `type`/`aggregate` 进 UI | 引擎支持，UI 未暴露 | 可拖 | 缺省按数据推断，可用 |
| 画布与协作收敛接入 Yjs | 纯函数契约，未接运行时 | 可拖 | 单机画布可用；多人画布未验 |
| 章纲提取跨章跳转 | 用定时等待，非事件驱动 | 可拖 | 慢设备可能偶发丢跳转 |
| 修订侧车保存基线全文 | 体积随基线增长 | 可拖 | 改为按 id 引用快照再压缩 |
| 移动端浏览器端到端 / SW 产物 | 未实测 | 可拖 | 桌面优先；移动是加分项 |
| 插件渲染器进导出格式下拉 | 只能经 profile 指定 | 可拖 | 能力存在，入口未接 |
| `chapter.save` 首帧全量不派发 | 边界未覆盖 | 可拖 | 仅影响插件事件完整性 |
| 协作 B/C 档评论权限与工作流 | 只留缝 | 砍 | 多人协作明确不做 |
| 平台化（发布/社区/收益/合规预审） | 不做 | 砍 | 发行档不覆盖 |
| CAD/三维、游戏运行时脚本 | 不做 | 砍 | 超出创作工具边界 |
| Tauri / 移动原生栈 | 不做 | 砍 | 移动需求出现前不迁 |
| 正文以文件为源、追加式事件日志 | 用户已暂缓 | 砍 | 已明确暂缓 |

## 三、v0 建议范围

- 纳入：纯写作核心循环、章节/结构、数据视图（表格/卡片/图表/画布）、导出（md/txt/html/odt + 既有 pdf/epub/docx）、版本与回滚、备份与恢复、设置与数据存储、AI 增强（可整体关闭）、资源型插件。
- 有条件纳入：逻辑型插件执行——以"补一个签名示例插件端到端验证通过"为前提，否则 v0 保持默认不注入执行端口。
- 不纳入：多人协作、平台化、移动端专项、CAD/三维、游戏运行时。

## 四、发布前硬门槛

1. `npm run verify` 非零即停；`npm run test:e2e` 与打包冒烟在 CI 通过。
2. 上文第一节手工验收逐项通过并留记录。
3. 版本号（`package.json` 单点）与 CHANGELOG 同步；机器标识（appId/数据目录/包名）保持不变。
4. 体积预算复核通过，或完成一次懒加载优化后再发布。
