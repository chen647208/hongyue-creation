# 43 无障碍与国际化品质

## 背景与问题

无障碍只在书架/工作台/设置三屏跑 axe 棘轮，其余面板未纳入；对比度问题靠平台差异才暴露（同一元素 Windows 判为不确定、Linux 判为违规）；国际化存在命名空间与键的漂移风险，缺少"中英对齐"的自动校验。

## 目标

- 无障碍从三屏扩到全部面板：面板默认纳入 axe 审计，欠账以棘轮收口，只减不增。
- 对比度达 AA：正文与提示文字在浅底与深底都满足对照比例，边界值留出余量。
- 国际化可校验：中英键集一致、无未翻译、无孤儿键；切换语言后界面无回退残留。

## 非目标

- 不追求 AAA 全项（先达 AA）。
- 不引入第三方无障碍组件库改变现有交互形态。

## 设计

1. 审计面：把 axe 审计做成可复用用例，覆盖书架、工作台各分区、设置各页签、世界/时间线/视图等主要面板；每屏产出违规摘要（含节点选择器与对照比），已知欠账登记基线上限。
2. 对比度：语义色统一取值，边界场景（次级文字在浅底/深底、徽章底色）取安全值；CI 跑真实浏览器审计，避免平台判定差异。
3. 键盘与焦点：所有交互有键盘等价；弹层焦点进入与返回正确；全局对话框置顶且不被功能弹窗吞掉焦点。
4. 动效：尊重减少动效，动效不作为唯一状态指示。
5. 国际化校验：脚本比对中英键集，报告缺失/多余/未翻译；语言切换后断言关键界面文案来自目标语言。
6. 可读标签：图标按钮有可读名称，表单控件有关联标签。

## 验收

- 全部主要面板纳入 axe 审计，出现违规即失败；欠账条目数与基线一致或更少。
- 对比度用例在 Linux 与 Windows 都通过（不再依赖平台差异）。
- 中英键集比对零缺失、零多余；切换语言后关键界面无源语言残留。
- 键盘可走完：建书、进工作台、切分区、开设置各页签、开关全局对话框。

## 风险

- 审计面扩大带来大量历史欠账：以棘轮分批收口，先记录后修复，禁止一次性放宽阈值。
- 对比度改动影响视觉快照：改动颜色后刷新对应平台基线再提交。
