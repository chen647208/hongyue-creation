# 39 编译与导出

## 背景与问题

导出已覆盖 txt/md/html/rtf/pdf/ePub/DOCX、封面与 Fountain，并有"选择→变换→渲染"的 Build Profile。相比专业写作工具的"编译"仍缺细节：前置页、分隔符、章节页眉页脚、按目标（稿件/设定集/大纲）的差异编排，以及 ODT；分镜与口播类内容缺对应输出。

## 目标

- 编译模板可配置：前置页、目录、章节分隔、页眉页脚、占位符替换、字体与行距。
- 编译目标分明：成稿、设定集、大纲、分镜表各取所需集合与排版。
- 格式补齐：ODT；分镜表导出为表格类格式；口播稿时长标注。
- 与现有管线一致：只扩展 profile 与渲染器，不改数据模型。

## 非目标

- 不做排版级 DTP（复杂图文混排、杂志版式）。
- 不做平台投稿格式的自动适配（平台侧变化快，交给插件）。

## 设计

1. Profile 扩展：在现有 Build Profile 上增加编译设置——目标（成稿/设定集/大纲/分镜）、包含集合与顺序、分隔符、是否生成目录、页眉页脚、字体/行距/页边距、封面。
2. 占位符与条件：支持按实体类型条件渲染（如仅成稿含正文、设定集只含设定条目），占位符取作品元信息。
3. 渲染器：在现有 txt/md/html/rtf/pdf/ePub/DOCX 基础上补 ODT；分镜目标输出为表格（每镜：镜号/景别/画面/台词/音效/时长）；口播目标保留时间标注。
4. 预览：编译前用同一管线渲染预览，复用现有阅读器预览，所见即导出。
5. 可分享：profile 与模板可导出/导入 JSON，便于分发。

## 验收

- 四个编译目标各产出一份示例文件：成稿（含前置页与目录）、设定集（仅设定条目）、大纲（层级）、分镜表（表格）。
- ODT 用常见办公软件可打开且章节层级正确。
- 预览与导出内容一致（同管线）。
- profile 导出再导入后结果一致。
- 单测：profile 解析、条件包含、占位符替换、各渲染器关键结构。

## 风险

- 格式细节多：以"结构正确 + 可打开"为底线，精排靠后续迭代与插件。
- 体积：文档生成库需评估包体积，优先复用已有能力。
