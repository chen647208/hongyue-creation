# 37 AI 上下文注入与可信检索

## 背景与问题

生成时用户手动挑选要注入的知识库与世界观条目，长篇里反复挑、容易漏；检索已具备 FTS 与向量融合，但注入内容没有"谁说的、出处在哪"的逐字核对，外部资料与模型输出混在一起时无法追溯。

## 目标

- 上下文按规则自动注入：给定关键词命中即把对应设定/条目按预算注入，减少手动挑选。
- 注入的内容可溯源：每条来源标注出处，引用文本与原文逐字一致，不一致即标记。
- 保持"可关闭"：关掉注入即回到纯手动，纯写作路径不受影响。

## 非目标

- 不做联网抓取与事实核查服务。
- 不改三档审批与工具契约。

## 设计

1. 注入规则：每条设定可声明触发词与作用域（本书/通用）、优先级、最大 token。命中当前任务或活动章节时按预算装配；预算与顺序由现有提示装配器的 section 机制承载。
2. 装配顺序：身份与体裁 → 作品元信息 → 命中设定（按优先级与预算截断）→ 索引摘要 → 历史 → 技能 → 工具 → 用户任务；超预算时按优先级裁剪并记录被裁条目。
3. 可见性：生成界面显示本次实际注入的条目清单与占用预算，可临时开关单条。
4. 溯源与逐字校验：注入片段带来源（知识库条目 / 章节 / 设定 / 外部文件）与位置；对"引用型"片段，注入前与原文逐字比对，不一致的降级为提示或剔除，并在报告中标出。
5. 可信围栏：外部资料与网页内容一律作为不可信输入注入（已有 `<untrusted>` 机制），不得直接进入系统级提示；工具结果同样处理。
6. 检索联动：语义与全文融合结果按实体分组，注入条目可跳回来源。

## 验收

- 命中的设定在不手动挑选时被注入，生成界面能列出条目与预算，单条可关。
- 引用型片段与原文逐字不一致时，该片段被标出且不参与注入。
- 关掉注入规则后，生成所用的上下文与当前手动挑选行为一致。
- 提示装配有单测：命中、优先级、预算裁剪、逐字校验、不可信围栏。

## 风险

- 过度注入挤占预算：以优先级与预算硬上限约束，并记录被裁条目供用户调参。
- 触发词误命中：作用域默认限本书，跨书命中需显式开启。
