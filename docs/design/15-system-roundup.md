# 15 系统补齐：标签分组、托盘自启、代理、崩溃上报

## what

1. **标签分组**：`Project.tags?: string[]`（缺席=[]，免迁移）；
   书籍库按标签过滤 + 新建/卡片菜单打标。
2. **托盘自启**：托盘图标（复用应用图标）+ 最小化到托盘 + 开机自启开关
   （`app.setLoginItemSettings`，设置页）；关闭窗口默认最小化到托盘，
   右键菜单退出。
3. **代理**：设置页 HTTP/SOCKS5 地址 + 测试连接；主进程网关 fetch 经
   `ProxyAgent`（undici），空地址即直连；Ollama 本地豁免提示。
4. **崩溃上报**：转储默认只本地留存；用户在设置里开启且宿主配置了
   上报端点才上传。

## why

- 对标 Obsidian（标签/文件夹组织）、Cherry Studio（代理+测试）、
  VS Code（托盘/崩溃遥测开关）。

## 验收标准

1. 单测：标签过滤；代理地址校验。
2. 手工：打标过滤；托盘退出/恢复；代理开/关对照。
3. 不回归：`verify` 全绿；缺席配置全部回退默认。
