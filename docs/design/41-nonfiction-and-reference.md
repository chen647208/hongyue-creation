# 41 非虚构与引用

## 背景与问题

非虚构、报告、论文、翻译/改编属于通用创作件的目标域，但当前缺引文与参考文献能力，也没有原文与译文的对照视图。用小说侧的实体/章节模型硬套这四类，结构上不成立。

## 目标

- 非虚构可用：引文（直接/间接）、脚注/尾注、参考文献表、交叉引用。
- 翻译/改编可用：原文与译文段落对齐的对照视图，可逐段确认。
- 全部落在通用数据模型上，不引入专用表。

## 非目标

- 不做文献管理器的全功能（海量条目库、元数据联网抓取）。
- 不做引用格式的出版级精细排版（先覆盖常用样式）。

## 设计

1. 引文与参考文献：以实体类型"参考文献"承载条目（作者/题名/年份/来源/标识符）；正文用引用标记挂到条目；导出时按选定样式生成文末参考文献表与文中引用编号；重复引用自动合并编号。
2. 脚注/尾注：正文挂脚注节点，导出到支持格式时落为脚注，纯文本格式回落为文末注。
3. 交叉引用：指向章节/图表/设定的编号引用，编号随结构变动重算（复用已有章节自动重编号思路）。
4. 对照视图：把原文段落与译文段落按对齐关系成对呈现，可逐段确认/改写状态；对齐关系存为段落间的关联，不改正文结构。
5. 样式：内置常见引用样式，按名称选择；样式定义为数据，可扩展。
6. 复用：文末列表、交叉引用与编号都走现有编译管线（39）的渲染器。

## 验收

- 一份含 3 条引文与 2 处脚注的非虚构示例可导出为带参考文献表与脚注的 DOCX/PDF。
- 同一文献重复引用编号一致，删除其中一处后编号自动重排。
- 交叉引用在章节增删后编号正确。
- 对照视图能逐段确认，确认状态可持久化，重启不丢。
- 单测：引用编号与重排、脚注导出映射、对齐关系读写。

## 风险

- 引用样式复杂度：先覆盖常用几类，样式数据化便于扩充。
- 对照视图与正文同源：对齐关系作为标注层，避免第二份正文。
