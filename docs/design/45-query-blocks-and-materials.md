# 45 查询、块引用与素材隔离

## 背景与问题

多视图引擎能按类型/字段/排序/分组呈现数据，但视图条件是固定的界面状态，不能"保存一个条件、随数据自动更新"；正文以章节/段落为最小单位，无法引用或嵌入某个具体片段；素材（研究、废稿、设定草稿）与成稿混在一起，统计与导出都被污染。这三件事在成熟知识工具里都有成熟范式（保存的查询、块级引用、素材隔离），本仓缺。

## 目标

- 保存的查询：视图条件与列/公式/聚合可存为数据，随数据变化自动重算，可多套并存、可内嵌到正文。
- 块级引用与嵌入：正文片段有稳定标识，可跨章节引用（引用显示）与嵌入（内容同步），位置变动不断链。
- 素材隔离：一处标记即让素材不进统计、不进导出、不进成稿视图。
- 全部由既有实体/字段/视图投影，不引入第二份真相。

## 非目标

- 不做每日笔记式 outliner（长文需要稳定结构，不做以天为单位的范式）。
- 不做通用图数据库查询语言（先做受限的过滤/公式/聚合，表达力够用即可）。
- 不做云同步。

## 设计

1. 视图即数据：把视图定义扩展为可保存对象——集合（类型/标签/字段条件，支持与或非与递归）、列与公式（引用字段、做简单计算）、聚合（计数/求和/均值/最长/最新）、呈现形态（表/卡/图/看板/时间线）、排序与分组。视图定义可命名、可多套、可导出导入。
2. 动态重算：视图是纯函数投影，数据变更后按需重算并缓存，缓存失效由数据版本驱动。
3. 块级标识：正文的段落/场景/清单项获得稳定标识；标识与内容分离，重排与编辑不改标识。
4. 引用与嵌入：引用显示为指向该块的链接（带上下文预览），嵌入把该块内容实时投影到目标位置；被引用块删除时给出失链提示而不是静默消失。反向引用面板列出"谁引用了我"。
5. 素材隔离：以类型或字段标记素材；标记为素材的内容默认不进字数统计、不进成稿编译、不进按成稿口径的视图；导出设定集时反而优先取素材。
6. 边界：视图与引用是投影层，不改六实体；嵌入不复制内容。

## 验收

- 保存一个"未回收伏笔 + 按重要度排序"的视图后，添加或回收伏笔时该视图自动更新；视图可导出再导入且结果一致。
- 正文中引用一个设定块，改动该块后引用处预览同步；块被删除后引用处显示失链并可跳修复。
- 标记为素材的章节不计入字数与码字统计，成稿编译不含它，设定集编译包含它。
- 视图重算与块引用有单测；失链与素材过滤有测试。

## 风险

- 公式表达力膨胀：限定为受限子集，超出范围交插件脚本层（47）。
- 嵌入带来的循环引用：检测环并拒绝自嵌入/互嵌。
