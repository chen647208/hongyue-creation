# 44 创作范式地图与跨域能力

## 背景与问题

通用件的竞争力来自"每个创作类型都用对了该领域的范式"，而不是把功能平铺一遍。各领域成熟工具的核心是范式（数据结构与交互骨架），不是功能清单；工科图示、可编程文档、剪辑与版本控制等领域里还有大量可直接迁移的机制。当前缺少一份把"各领域范式 → 可迁移机制 → 本仓落点"连起来的图，导致借鉴零散、重复造轮子。

## 目标

- 给出各创作领域与跨领域工具的**范式地图**（每种工具一句话讲清它的数据/交互骨架）。
- 抽出可迁移机制，并落到本仓既有底座（六实体、类型/字段、多视图、DSL、插件沙箱、Yjs、AI 治理）上，判定"做成核心 / 视图类型 / 资源型插件 / 逻辑型插件 / 不适用"。
- 产出分档清单（值得抄 / 可选 / 不适用）与后续设计稿索引。

## 非目标

- 不照搬实现，尤其不抄 copyleft 代码（novelWriter/Zettlr/Twine/Manuskript/bibisco 为 GPL，Trilium/Logseq 为 AGPL，SillyTavern 为 AGPL；只借鉴设计）。
- 不引入第二套真相源（图谱/画布/查询都由既有实体投影，不另存一份）。
- 不在核心引入重型运行时（Java/原生二进制/三维引擎）。

## 设计

### 一、范式地图

| 领域 | 代表工具 | 范式一句话 |

### 二、跨域可迁移机制（提炼）

1. **片段化文档**：写作单元是片段，章节是片段的容器；多种呈现（连续编辑 / 卡片墙 / 大纲）。
2. **编译管线**：来源集合 + 变换 + 模板 → 多目标输出；写作外观与输出外观分离。
3. **文档级快照 + diff + 回滚**：和某个时间点比差异，再决定回滚；AI 改前自动快照。
4. **元数据/属性**：正文与属性分离，属性类型化，视图与查询都读同一份属性。
5. **保存的查询/动态视图**：把"条件 + 列/公式/聚合 + 视图形态"存成数据，随数据自动更新。
6. **块级稳定 ID 与引用/嵌入**：块是原子且位置无关；引用与反链是同一份数据的投影。
7. **素材与正文隔离**：一处标记即可让素材不进统计、不进导出。
8. **结构即数据**：剧本元素、镜头字段、分支选择项都可查询、可校验、可多视图。
9. **稳定编号与插场后缀**：重排内容不改锚点，人读编号与稳定 ID 分离。
10. **分支图确定性校验**：可达性、死链、死端、未定义变量在交付前静态报告并可点击定位。
11. **文本即图 / 声明式编码**：纯文本或"字段→通道"声明，经布局引擎派生图形。
12. **节点图编程/数据流**：节点=操作、连线=数据流，图可求值；非破坏、可封装复用。
13. **可编程画布 + 可插拔形状**：画布是 SDK，形状/工具由贡献点提供。
14. **非破坏多轨时间线**：草稿矩阵与成稿轨道同源；trim 语义保留可回溯。
15. **上下文注入引擎（lorebook）**：关键词/正则/语义触发 + 递归 + 权重 + 位置 + 时效。
16. **宏/脚本层**：管道 + 变量 + 条件循环 + 命名子程序 + 事件触发，服务非开发者。
17. **agent checkpoint 与三档门**：改前快照可回滚、审批暂停点可恢复、子代理隔离上下文。
18. **两套版本门**：正式历史（提交式）服务长期与协作，试错快照（checkpoint 式）服务 agent。

### 三、本仓落点

现有底座：六实体（nodes/edges/attrs）+ 类型/字段/顺序/视图（schema v5）+ 多视图引擎 + `core/dsl` 与 CodeMirror + 插件沙箱（QuickJS 无 DOM 计算 + null-origin iframe 管 UI）+ Yjs 协作 + AI 三档审批与事件流。

| 机制 | 落点 | 形态 |
|---|---|---|
| 片段化文档 / 编译管线 | 既有章节/分组 + Build Profile | 核心（已有，深化见 39） |
| 快照 + diff + 回滚 | 快照 + 修订已有，补"比差异/回滚" | 核心（38） |
| 保存的查询/动态视图 | 视图配置扩展为 filter/formula/aggregate | 核心（45） |
| 块级稳定 ID + 引用/嵌入 | 索引器已有硬链接/回链，补块级 id 与嵌入 | 核心（45） |
| 素材/正文隔离 | 实体类型或字段标记 + 统计/导出过滤 | 核心（45） |
| 结构即数据（镜头/分支/引文） | 类型模板 + 字段 | 类型模板（39/41/42） |
| 文本即图 / 声明式编码 | `core/dsl` + 视图类型 `diagram`/`chart` | 资源型插件 + 视图（44 落地项） |
| 节点图编程/数据流 | edges 加端口语义，图视图可求值 | 逻辑型插件（沙箱内） |
| 可编程画布 | 视图类型 `canvas`，序列化用 JSON Canvas | 内置视图 + 插件贡献形状 |
| 非破坏多轨时间线 | 双轴时间线已有，补 trim 语义与草稿矩阵 | 核心（46） |
| 上下文注入引擎 | 提示装配器的 section 机制 | 核心增强（37） |
| 宏/脚本层 | 插件逻辑贡献 + 事件总线 | 插件 v1（44 落地项） |
| agent checkpoint | AI 事务前自动快照 + 恢复 | 核心增强（46） |
| 两套版本门 | 既有快照/修订 + 引入提交式历史？ | 待评估（46） |

### 四、分档清单

**值得抄**
- 片段化文档 + 编译管线（Scrivener/Pandoc 思路）。
- 文档级快照 + diff + 回滚（Scrivener）。
- 元数据/属性 + 保存的查询/动态视图（Obsidian Bases/Scrivener Collections）。
- 块级稳定 ID + 引用/嵌入 + 反向链接（Logseq/Obsidian）。
- 素材与正文隔离（Ulysses）。
- 结构即数据：镜头字段、分支变量、引文条目（StudioBinder/Ink/Quarto）。
- 稳定编号与插场后缀（Final Draft）。
- 分支图确定性校验（ChatMapper）。
- 文本即图 / 声明式编码（Mermaid/Vega-Lite）。
- 开放画布格式 JSON Canvas 作为画布序列化。
- 上下文注入引擎（SillyTavern lorebook）。
- agent checkpoint + 三档门 + 子代理（Cursor/LibreChat）。

**可选**
- 节点图编程/数据流视图（范围易失控，限沙箱内求值）。
- 标准符号层（UML/BPMN/SysML，作为类型模板 + 渲染器插件）。
- 图表视图（Vega-Lite 运行时体积约数百 KB，懒加载插件、不进默认发行档）。
- 可编程画布引入第三方 SDK（tldraw：可能引入第二套 store 与同步，优先自研 headless + 复用 Yjs）。
- 自托管多 DSL 渲染服务（Kroki：依赖服务，可选外部渲染器）。
- 宏语言完整特性（先命令管道 + 变量 + 条件循环，调试器后置）。
- PERT 依赖网络（并入时间线依赖箭头，不单开视图）。

**不适用**
- CAD/三维参数化与节点合成（OpenSCAD/Blender/Houdini/Fusion）：与文本创作不同层，另起产品线。
- 游戏运行时脚本（Blueprints/Shader Graph 的执行语义）：只取数据流编辑，不取运行时。
- 闭源云工具的格式/依赖（Figma/Miro/Notion）。
- mxGraph XML 作为内部格式（只借"声明式形状 + 版本化形状库"设计）。
- PlantUML（GPL-3.0）与 Graphviz 等重型运行时进核心。
- 纯云锁定、无本地明文的范式。
- Word Master Document（官方限制 255 子文档，易损）。
- 行内红绿 track changes 与建议模式二选一（长文取建议模式）。

## 验收

- 每一项"值得抄"给出可运行的纵向切片：用一份示例工程演示该范式，且不引入第二真相源。
- 能力落地只经"核心 / 视图类型 / 资源型插件 / 逻辑型插件"四类落点之一，出现第五类落点即评审。
- 许可审查通过：不引入 copyleft 代码，重型运行时只在可选插件内。

## 风险

- 范围失控：以本表"可选/不适用"为闸门，核心只收数据模型与扩展机制。
- 借范式变成抄形态：验收要求每项都能映射回既有实体/字段/视图，否则退回。
- 性能与体积：图表/画布/DSL 渲染器按需加载，纳入体积预算。
