# 47 跨域视图与脚本层

## 背景与问题

跨领域借鉴里价值最高、又能复用既有底座的三类能力是：文本即图（用文本定义关系图/流程图）、可编程画布（自由摆放节点并连线）、宏/脚本层（让非开发者编排流程）。本仓已有 DSL 与 CodeMirror、多视图引擎、插件沙箱与事件总线，缺的是把它们组合成可用的视图类型与脚本层。

## 目标

- 图视图：用文本 DSL 定义关系/流程/时序，渲染为可交互图；也可直接拖拽编辑并回写 DSL。
- 画布视图：自由坐标画布，节点可放实体、章节、便签、图片，节点间连线；序列化采用开放画布格式。
- 图表视图：声明"字段→视觉通道"，由编译器派生轴/图例/比例尺。
- 脚本层：命令管道 + 变量 + 条件循环 + 命名子程序 + 事件触发，供非开发者编排；与插件（JS/WASM）分层。
- 四者都以视图类型或插件形态提供，可关闭，关闭后纯写作不受影响。

## 非目标

- 不在图/画布内做三维、合成或运行时脚本。
- 不引入重型图渲染运行时进核心（图 DSL 先支持常用子集）。

## 设计

1. 图视图：视图类型 `diagram`，字段存 DSL 文本；解析→布局→渲染三段；布局引擎可换；支持拖拽微调并把结果回写为坐标覆盖（不破坏 DSL 语义）。先支持流程图、关系图、时序图、思维导图四类常用形态。
2. 画布视图：视图类型 `canvas`，节点带坐标与尺寸，边表达连线；序列化用开放画布格式（节点 + 边 + 任意扩展字段，数组序即层序），可导入导出与外部工具互通；节点可指向实体/章节或纯便签。
3. 图表视图：视图类型 `chart`，配置"字段→通道"映射（如颜色=角色、大小=重要度、横轴=故事时间）与图形类型；由声明派生轴与图例；渲染器按需加载。
4. 脚本层：以命令为单元，支持管道传递、变量与作用域、条件与循环、命名子程序、参数；挂点覆盖消息前后、条目激活、标签变更、勾选、定时；脚本产物与 AI 工具、插件能力同权同审计。脚本与导出渲染器的描述符形态、函数引用、能力白名单与沙箱执行协议见 49 篇；本层只消费 49 的 `ScriptRegistry` 声明。
5. 分层：模板与视图是数据（可分发），脚本是低代码层，插件是代码层；三层都能被停用，停用后回落到手动路径。
6. 协作：画布/图视图的并发编辑复用 Yjs，并采用"元素版本号 + 随机决胜 + 墓碑 + 分数排序"的确定性收敛不变量，避免同元素抖动。

## 验收

- 图视图：一份流程与一份关系图由文本生成并可拖拽微调后回写，重开一致。
- 画布视图：摆放节点连线后导出，用外部支持同格式的工具可打开，再导入回来结构一致。
- 图表视图：给定字段映射产出的图，轴/图例由声明派生；运行时按需加载，不进默认发行档。
- 脚本层：一段脚本能读事件、改字段、调用工具并通过审批写入；停用脚本层后手动流程完整。
- 收敛不变量有单测；图/画布/脚本各有关键路径 E2E。

## 风险

- 图 DSL 表达力：先常用子集，复杂图形交插件。
- 画布双真相：画布是实体/章节的投影，坐标与连线存为视图数据，不复制内容。
- 脚本安全：脚本层与插件同走沙箱与权限，写入走 AI 三档门。
